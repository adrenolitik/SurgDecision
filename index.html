Как устроено решение

Типизированный шаг вместо текста

Агент не пишет рассуждение. На каждом шаге он отвечает на вопрос с закрытым списком вариантов: «Какое обследование выполнить следующим?», «Есть ли симптом Мёрфи?». Ответ — вероятность для каждого варианта. Детерминированный контроллер применяет фиксированное правило: выполняет самый вероятный вариант. Шаг, вероятности, правило и полученные данные записываются в журнал.

Дифференциальный диагноз

Априорные вероятности обновляются по теореме Байеса. Для каждого симптома задана пара отношений правдоподобия: LR+ (симптом есть) и LR− (симптома нет). Отношение шансов умножается на LR, затем вероятности нормируются по всем вариантам дифференциала. Ответ «нет данных» не изменяет распределение.

Выбор следующего действия

Для каждого доступного этапа вычисляется ожидаемая информационная ценность: сумма дискриминирующей силы неотвеченных признаков, взвешенная текущей вероятностью альтернатив, с поправкой на «стоимость» метода. Вариант с наибольшим весом выполняется. После трёх этапов в меню появляется заключение: его вес растёт с уверенностью распределения. Заключение можно сформировать досрочно.

Лечение

Степень тяжести определяется по профильной шкале (Alvarado, Tokyo 2018, BISAP, Hinchey, Boey, Glasgow–Blatchford, индекс странгуляции, перитонеальные признаки при ишемии). План лечения выбирается по степени тяжести и модифицируется с учётом аллергии, беременности, СКФ и антикоагулянтов.

Границы применимости

Таблицы правдоподобия — дидактические, собранные из литературы, а не откалиброванные на когорте. Инструмент не валидирован как медицинское изделие, не учитывает педиатрию, беременность (кроме отдельных указаний) и локальную резистентность. Любое решение проверяйте по действующему протоколу учреждения.
